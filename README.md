# Frolvy

Windows builds of **Frolvy**, a 3D animation and rigging program: joints, controls, IK, skinning, a Python API.

Download the latest build from [Releases](../../releases/latest):

- `Frolvy-<version>-win64.exe` - the installer (recommended). Installs into Program Files, adds a Start menu shortcut, and uninstalls from Settings. Includes everything it needs: the Visual C++ runtime, Python and ffmpeg.
- `Frolvy-<version>-win64.zip` - portable. Unzip anywhere and run `Frolvy.exe`; no administrator rights needed.

Requires Windows 10 or 11 (x64) and a graphics driver with OpenGL 4.6.

This repository holds releases only. Frolvy was called AnimationDCC before version 0.9.4.
